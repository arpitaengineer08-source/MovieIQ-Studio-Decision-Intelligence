# 🎬 MovieIQ – Studio Decision Intelligence

An end-to-end Machine Learning and Business Intelligence dashboard that predicts movie box office success while providing interactive analytics, statistical insights, and business recommendations.

Built with **Python**, **Streamlit**, **Machine Learning**, and **Plotly** for an engaging and professional analytics experience.

---

## 🚀 Features

### 📊 Performance Dashboard
- KPI Cards
- Total Movies
- Average Budget
- Average Revenue
- Success Rate
- Average ROI
- Genre Distribution
- Budget vs Revenue Analysis
- Revenue Insights

### 🧪 Hypothesis Testing
- Statistical Analysis
- Correlation Matrix
- Budget vs Revenue Relationship
- Runtime vs Rating Analysis
- p-value Interpretation
- Test Statistics
- Business Conclusions

### 🎯 Prediction Engine
Predict a movie's expected performance using:
- Budget
- Genre
- Runtime
- Release Year
- Popularity
- Rating
- Other movie attributes

Outputs:
- Predicted Revenue
- Success Probability
- Revenue Category
- Confidence Score

### 💰 Budget Prediction (What-If Analysis)
Experiment with different budgets and visualize:
- Expected Revenue
- ROI
- Profit/Loss
- Success Chance
- Budget Impact

### ⚖️ Movie Comparison
Compare multiple movies based on:
- Budget
- Revenue
- Rating
- Runtime
- Genre
- Release Year

Visual comparisons include:
- Comparison Tables
- Bar Charts
- Radar Charts

### 📁 Raw Data & Export
- Dataset Preview
- Search & Filter
- Download CSV
- Download Excel
- Export Prediction Results

### 💡 Insights & Recommendations
Generate business insights including:
- Best Performing Genres
- Budget Recommendations
- Revenue Trends
- Studio Decision Support
- Final Conclusions

# ▶️ Installation

Clone the repository

```bash
git clone https://github.com/your-username/MovieIQ-Studio-Decision-Intelligence.git
```

Move into the project

```bash
cd MovieIQ-Studio-Decision-Intelligence
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
