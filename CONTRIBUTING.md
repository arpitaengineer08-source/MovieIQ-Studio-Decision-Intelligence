# Contributing

Thanks for your interest in contributing to MovieIQ Studio.

## Getting started
1. Fork and clone the repository.
2. Create a Python virtual environment.
3. Install the dependencies with `pip install -r requirements.txt`.
4. Follow the README to run the analysis and launch the application.

## Contribution guidelines
- Keep data preparation and analytical assumptions documented.
- Do not present correlations or model outputs as causal conclusions.
- Add tests or reproducible validation notes for changes to analysis or application behaviour.
- Do not commit credentials, private datasets or local environment files.
- Keep charts and dashboard explanations consistent with the underlying data.

## Pull requests
Describe the problem, the changes made, validation performed and any impact on analytical outputs. Include screenshots for visual changes when relevant.
